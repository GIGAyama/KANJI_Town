# 更新の記録

マイ漢字タウンの変わったところです。

## 2026-11-15
- マイドリルを、しめきりつきの宿題として配れるようにしました
- 授業で習った字だけを、日付を決めて前もって配れるようにしました
- マイドリルから、紙で配る縦書きの漢字テストを印刷できるようにしました
- 同じドリルのリンクをもう一度開いても、2つ保存されないようにしました
- 書き順と書体をアプリに入れ、学校のネットが止められていても使えるようにしました
- 4〜6年の漢字の学年わけを、いまの教科書に合わせました
- 漢字の読みを、常用漢字表の読みに合わせました
- 学習の画面に「やめる」ボタンをつけました
- スマホでも、学年えらびと学習を始めるボタンがすぐ見えるようにしました
- 町が大きくなっても、ホームの町が重くならないようにしました
- 毎日のテストとボスの問題を、文の中の◯を書く形にしました
- 例文のふりがなのまちがいを直しました
- ボスバトルとサバイバルで、書き順がちがう字を正解にしないようにしました
- ボスバトルなどで前の問題の線が残り、正しく書いても不正解になるのを直しました
- 何も書かずに「よくできた」を選べないようにしました
- 小さく書いても、形と書き順が正しければ合格するようにしました
- 画面を回しても、書いた字や練習の回数が消えないようにしました
- 小さな画面のテストで、下のほうの画がボタンに当たって書けないのを直しました
- ふりがなを「学年より上の字だけ」などから選べるようにしました
- 文字の大きさを3段階から選べるようにしました
- テーマの色を濃くし、ボタンや説明の文字を読みやすくしました
- 図鑑で、ひらがなの読みでも漢字が見つかるようにしました
- 書き順を読めない字も、音読は続けられるようにしました
- 書き順のデータが読めないとき、ドリルのテストが0点にならないようにしました
- ボスで同じ字が続いても、復習が何か月も先に延びないようにしました
- ボスバトルの「やめる？」を出しているあいだは、時間が進まないようにしました
- ボスやサバイバルの途中でやめても、答えた字の記録が残るようにしました
- 学年の字を習い終えても、いろいろな字を練習できるようにしました
- 休みが続いたあとの連続日数を、正しく出すようにしました
- 書き出したファイルに学習の記録も入れ、読みこみを取り消せるようにしました
- バックアップの読みこみで、ちがうファイルを選んでも記録が消えないようにしました
- 「すべてのデータを消す」のあと、前の子のとりくみが見えないようにしました
- 2つのタブで開いたときに、記録が古いもので上書きされるのを直しました
- 記録が読めないときに、真っ白な画面のままにならないようにしました
- ボタンを続けて押したときに、EXPやコインが二重に入るのを直しました
- 4けたの数字で受け取るとき、先生と同じしるしで確かめられるようにしました
- ドリル名に、名前や出席番号を書かないよう注意書きをつけました
- 設定した音の大きさが、次に開いたときも残るようにしました
- まちづくりで置いた建物が、もどるボタンで消えないようにしました
- 町をマウスで動かすと、まちづくり画面に移ってしまうのを直しました
- 建物の強化をすると、元の建物が上位の建物にかわるようにしました
- まだ進めないタブを押したとき、理由が出るようにしました
- 住民がいないときに「とても ふまん」と出ないようにしました
