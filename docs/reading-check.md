# 音読チャレンジ（発声チェック）の設計

## ねらい

通常学習モードの音読フェーズは、従来「声にだそう！」と表示するだけで、
タップ1回で通過できた。音読（声に出して読むこと）には黙読より記憶定着が
高い産出効果の裏付けがあるため、「実際に声を出した」ことを確認し、
行動をごほうびで動機づける仕組みを追加した。

## 方式の選定

| 方式 | 採否 | 理由 |
|---|---|---|
| クラウド音声認識（Web Speech API） | ✗ | 音声がGoogleサーバーへ送信され「外部送信は一切行わない」方針に違反。オフラインで動かない。iOS Safari 非対応 |
| WASMローカル音声認識（Vosk等） | ✗ | エントリバンドル予算（220KiB）を大幅に超過。CDN遅延ロードはオフライン方針と矛盾 |
| **オンデバイス音量検出（採用）** | ✓ | `getUserMedia` + `AnalyserNode` のRMSのみ。依存ゼロ・完全オフライン・全端末対応。読みの正誤までは判定できないが「声に出す」行動自体を担保する |

音量検出では読みの「正しさ」は判定できないため、習得スコアへの反映は
`voiced` 証拠（+15点・上限75点）とし、`successes`（正解数）には数えない。
お手本読み上げ（端末内蔵TTS）と組み合わせ、正しい読みを聞いてから
声に出す流れで自己モニタリングを促す。

## プライバシー

- 音声波形は `AnalyserNode.getFloatTimeDomainData` で読み取った直後に
  RMS数値へ縮約し、**波形そのものはどこにも保持しない**。
- `MediaRecorder` は使わない。録音・保存・送信は一切ない。
- チャレンジ終了（クリア・中断・タブ非表示・画面遷移）で
  `MediaStreamTrack.stop()` と `AudioContext.close()` を必ず呼び、
  端末の録音中インジケーターを確実に消す。
- 学習ログ（study.v1）には音読チャレンジのレコードを追加しない
  （同一漢字の `firstTry` を消費して `firstTryCorrect` を壊すため）。
  習得への反映は `skillMastery`（`ext.skills` 経由の集計）のみ。

## 判定ロジック（src/utils/voice-activity.js）

純粋ステートマシン。`node --test` で検証できる。

1. **校正（500ms）**: 環境ノイズのRMS平均を計測し、
   `しきい値 = clamp(ノイズフロア + 0.015, 0.02, 0.08)` を決める。
   静かな教室でも敏感になりすぎず、騒がしい教室でも叫ばずに済む。
2. **検出**: しきい値以上のRMSが続いた時間を積算する。
   250ms未満で途切れた山（咳・タップ音・効果音）は破棄する。
3. **クリア**: 累計発声時間が1500msに達したら合格。
   10秒間声が検出できないときは「もうすこし おおきなこえで」と
   やさしく促す（×は出さない。stroke-grading.md の
   「全否定して学習意欲を折らない」原則に合わせる）。

調整パラメータは `src/constants/gameConfig.js` の `READING` に一元管理。

## フォールバック

- マイク非対応・許可拒否・管理ポリシーによるブロック → チャレンジカードを
  「マイクが つかえないから、声に だして よんでみてね」の案内に差し替える。
- チャレンジは任意のため、どの状態でも「書き順をみる」ボタンで
  次のフェーズへ進める（学習が詰まることはない）。
- 設定「音読チャレンジ」をOFFにするとカード自体を表示しない。

## お手本読み上げ（src/utils/tts.js）

- `speechSynthesis` のうち **`localService` な日本語音声だけ**を使う
  （リモート音声はテキストが外部へ送られるため使わない）。
- 端末に日本語ローカル音声がなければ読み上げボタンを表示しない。
- 設定「自動再生」ONのとき、音読フェーズ表示時に例文を1回だけ自動再生する。
- チャレンジ中はお手本を再生しない（スピーカーの音をマイクが拾って
  誤クリアになるのを防ぐ）。
